CV Optimiser

Single job · Batch (CSV / Excel) · Scraped jobs

Scrape new UK AI jobs (Indeed links you add here plus the job boards in scraper/portals.yml), match them against the CV with DeepSeek, then make a CV for the top matches automatically. Medium matches get a Generate CV button; low matches are listed for information only.

A link must contain the job key (jk= or vjk=). Indeed opens a visible Chrome window, about one minute per link; if it shows a “verify you are human” box, click it. The list replaces scraper/indeed_scrapper/links.txt.

    No Indeed links — the Indeed step is skipped.

    Each CV takes 1–3 minutes and 4 model calls. The other top matches get a button.

    Each match is one DeepSeek call. Leave empty to score every new job.

    The key is sent with the start request and with every Generate CV click. It is never stored, on the server or in the browser.
